ВОСХОЖДЕНИЕ — как поставить на телефон

1. Залей ВСЮ папку (index.html, sw.js, manifest.webmanifest и иконки) на любой бесплатный хостинг
   со ссылкой https — например, GitHub Pages или Netlify.
2. Открой ссылку в Chrome на Android → меню ⋮ → «Установить приложение» / «Добавить на главный экран».
   Появится иконка, приложение откроется на весь экран и будет работать даже без интернета
   (кроме нейронки).
3. Хочешь настоящий APK? Вставь свою https-ссылку на pwabuilder.com — он соберёт Android-пакет
   из этого же приложения.

Нейронка: профиль → «Нейронка Gemini» → вставь бесплатный ключ из aistudio.google.com.
Данные и фото хранятся только на телефоне — периодически жми «Скачать бэкап».
